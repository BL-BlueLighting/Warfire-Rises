## 这是什么？
一款基于 React, Ink 开发的终端型世界模拟游戏。
你没有打仗作战的地图，却有控制政治的神力。

## 世界观？
基于你开始这个存档的这一天，游戏会自动获取当天的各种基本信息。
如：
* USD->CNY/HKD 汇率。
* 当天世界局势，该局势会自动进行**不调用 AI**的提取关键字。
* ... 等等
该存档之后的走向将有**你**决定。
是使用<i>**控制台**</i>神力，还是使用金融手段让美元崩盘？
*(注：信息仅在游戏开始第一天获取，所以第一天加载可能比较久~)*

## 如何游玩？
参照游戏中执行 `help` 之后的结果。
每天发生的事件会变成简报发送到右边侧栏。
侧栏中会展示你操控的国家，事件，外交点数，军队耐力，国家耐力，世界崩坏度。
当 世界崩坏度 达到 100% 时，你操控的国家会变成造成这一切的国家。
是 TFR，还是 TNO？自己决定。
*(注：TFR = The Fire Rises, TNO = The New Order，均为 HOI4 模组)*
