# Internationalization / 国际化

## File Format / 文件格式

Language files use `key: value` format, one per line. Lines starting with `#` are comments.

语言文件使用 `key: value` 格式，每行一个。以 `#` 开头的行是注释。

```
# File: langs/en-us.txt
title.fetching: Fetching world data...
title.gathering: Gathering exchange rates, news headlines, and global intelligence.
att.peaceful: Peaceful Cooperation
att.irreconcilable: Irreconcilable
```

## Adding a New Language / 添加新语言

### Step 1: Create the language file / 创建语言文件

Copy an existing file and translate each value:

```bash
cp langs/en-us.txt langs/ja-jp.txt
# Edit langs/ja-jp.txt — translate values, keep keys identical
```

### Step 2: Register the language / 注册语言

In `src/i18n/index.ts`, add to the `Language` type:

```ts
export type Language = "en-us" | "zh-cn" | "ja-jp";
```

### Step 3: Load at startup / 启动时加载

In `src/index.tsx`, add:

```ts
tryLoad("ja-jp", "ja-jp.txt");
```

### Step 4: Add to language command / 添加到语言命令

In `src/App.tsx`, add to the language switch check:

```ts
if (newLang === "en-us" || newLang === "zh-cn" || newLang === "ja-jp") {
```

## Using Translations in Code / 在代码中使用翻译

### In React components / React组件中

```tsx
import { useI18n } from "../i18n";

const MyComponent = () => {
  const { t, lang, setLang } = useI18n();
  return <Text>{t("title.fetching")}</Text>;
};
```

### In game logic (non-React) / 游戏逻辑中（非React）

```ts
import { t } from "../i18n";

const message = t("cmd.military.strike", { flag: "🇺🇸", name: "USA", cost: 15 });
// → "⚡ Precision strikes hit 🇺🇸 USA! ... Cost: 15% AE."
```

### With replacements / 带替换参数

```ts
t("sidebar.day", { day: 5 })
// → "Day 5" or "第5天"

t("cmd.diplomacy.improve", { flag: "🇨🇳", name: "China", cost: 10 })
// → "Relations with 🇨🇳 China improved (+15). Cost: 10 DP."
```

| Prefix 前缀 | Scope 范围 |
|--------|-------|
| `title.*` | Title screen |
| `eventlog.*` | Event log |
| `sidebar.*` | Sidebar panel |
| `statusbar.*` | Status bar |
| `gameover.*` | Game over screen |
| `app.*` | Main app |

| `help.subcmd.*` | Sub-command descriptions |

| `gov.*` | Government types |

| `war.*` | War system |
| `ai.*` | AI action messages |
| `force.*` | Force/coercion labels |
| `collapse.*` | World collapse log |
| `common.*` | Shared utilities |

## How It Works Internally / 内部工作原理

1. At startup, `index.tsx` reads both `.txt` files, parses each line as `key: value`
2. `loadLangFile(lang, text)` builds a `Map<key, {lang: value}>`
3. `t(key, replacements)` looks up the key in the map, gets the value for `currentLang`, applies `{placeholder}` replacements
4. If key is missing, `t()` returns the key itself as a visible fallback indicator
5. `setLanguage(lang)` updates the module-level `currentLang`, then `setLangState` triggers React re-render
